**Jewellery Operations and Project Tracker**

**Project Overview**

This project was created to simulate real-world Business Operations and Project Coordination activities in a jewellery retail environment.
The solution combines operational reporting, inventory monitoring, issue management, risk tracking, stakeholder reporting, and project tracking into a single Excel-based system.
The project was inspired by my experience working in jewellery retail operations.
________________________________________
**Objectives**
•	Monitor sales performance
•	Track inventory levels
•	Identify critical stock shortages
•	Manage operational issues
•	Track project actions and risks
•	Support stakeholder reporting
•	Create a management dashboard for decision-making
